# Rumor Detection with SLS Model

Implementation of "A Novel and High-Accuracy Rumor Detection Approach using Kernel Subtree and Deep Learning Networks" in PyTorch.

## Features
- **Kernel Subtree Feature Extraction**: Novel features based on influential nodes
- **SLS Model**: Separable Convolutions + LSTM + SENet architecture
- **Hybrid Prediction**: Deep learning with GBDT fallback for uncertain cases
- **Circle Loss**: Advanced loss function for better optimization
